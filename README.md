A beautiful, lightweight, and privacy-respecting widget extension built exclusively for the Breeze Weather app. No tracking, no ads, just the forecast.

## Breezy Weather

The data comes from [Breezy Weather](https://github.com/breezy-weather/breezy-weather), a privacy-respecting open source weather app.

### Content Provider

It receives the data from the [content provider](https://github.com/breezy-weather/breezy-weather/discussions/2089), so you need to setup Breezy Weather to allow this app to receive data.
